# .impeccable.md

Design context for RAM Watch — persisted for all future sessions.

---

## Design Context

### Users

Solo developer running Claude Code with MCP servers and ChromaDB on a Mac. Opens this tool when memory pressure spikes or Claude feels sluggish. Context: stressed, in the middle of a session, needs to act fast. The job to be done is triage — *see the situation clearly, kill what's safe, get back to work*.

### Brand Personality

**Slick. Opinionated. Alive.**

- **Slick**: Every pixel earns its place. No generic chrome, no scaffolding showing through. Feels like a tool a designer-engineer made for themselves.
- **Opinionated**: Strong visual hierarchy. Clear color semantics. Doesn't hedge on decisions — the gauge is the hero, the danger is red, the table is dense-but-readable.
- **Alive**: Data breathes. The gauge transitions feel physical, not cosmetic. Rows enter and leave with weight. Buttons have spring. The UI communicates that real things are happening.

### Aesthetic Direction

**Primary reference: macOS Activity Monitor** — native Mac density, tabular numerals, SF Pro, semantic color use. But elevated: Activity Monitor is utilitarian; RAM Watch should feel like the version a product designer at Vercel or Linear built for their own machine.

**Gauge vision**: 3D/sculptural — not a flat 2D ring. Think beveled arc segments with inner shadow and subtle depth, or a frosted-glass donut with raised edges. The gauge is the hero of the header; it should command attention and feel physically present in the UI.

**Dual theme**: Both light and dark should feel intentional — not an inverted palette. 
- **Dark**: Deep charcoal `#0f1117` background, the current foundation.  
- **Light**: Warm off-white (`oklch(97% 0.005 250)` or similar), blue-gray data, same semantic colors but more saturated to compensate for the brighter background. Neither theme should look like a developer forgot to invert something.
- Toggle: persistent (localStorage), accessible, placed in the header near the gauge.

**Anti-references**: Generic Tailwind admin templates, neon cyberpunk, flat dashboard-by-numbers layouts with uniform card grids. No unmodified library defaults passed off as finished design.

### Design Principles

1. **The gauge is the hero.** Every header layout decision serves the gauge. It should be sculptural, 3D-feeling, and sized to command. Not decorative — it IS the information.

2. **Semantic color is sacred.** Red = killable, amber = auto-restart, green = safe. Active = blue, wired = violet, compressed = orange, free = gray. These meanings must be consistent across gauge, badges, and buttons in both themes.

3. **Density with breathing room.** The table is dense by nature — many processes, many columns. Preserve that density; don't artificially inflate padding. But create rhythm with spacing, not uniformity.

4. **Motion communicates state, not decoration.** Gauge transitions = memory changed. Row slide-out = process killed. Button spring = action registered. Every animation has a job. None are purely cosmetic.

5. **Native Mac, elevated.** SF Pro Display, tabular numerals, macOS-style surface layering. Feels like it belongs in `/Applications`, not on a hosted SaaS dashboard.
